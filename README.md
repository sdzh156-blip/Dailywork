## 使用说明

学完一节课并通过对应验收后，在 `WITec-Alpha300R/PROGRESS.md` 中把该节的 `- [ ]` 改为 `- [x]`，填写日期、证据与简短总结。**未学习、未验收的课程一律不得提前标记完成。**

后续与 ChatGPT 按本仓库中的课程编号逐节学习；完成并确认验收后再更新 GitHub。设备操作必须遵守实验室安全规定和设备管理员要求。
