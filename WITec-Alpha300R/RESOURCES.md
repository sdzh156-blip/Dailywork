# 资料来源、适用范围和引用规则

## 用户提供的四份资料（不上传原始 PDF 到公开仓库）

1. `SOP-WITec-Alpha300.pdf`：主参考，**Control FIVE** 的 6.1 开机和预热、6.2 采集、6.3 数据处理、6.4–6.8 附件/特殊模式。资料设备配置不一定等于用户实机。
2. `SOP-R026-WITec-Alpha300R.pdf`：补充参考，使用 Control 6.2，涵盖校准、Mapping、SHG/低温等；**仅用于原理和差异对照，不将菜单照搬到 FIVE**。
3. `WITec_data_processing.pdf`：Project/数据处理核心参考，约第 6–48 页，含 Drop Actions、CRR、Sub BG、Fitting、Raman TV/Filter（第 22–25 页）、图像处理、Combine/Stat（第 40–41 页）、Analyze（第 42–44 页）和后续高级功能。
4. `TrueSurface.pdf`：TS 反馈追焦、物镜选择、Signal/Min/P/I/Focus Shift/ Retrace 参数与异常注意事项（共 5 页）。

原始 SOP 中部分页面标注内部使用、请勿转发。课程仅自编目录、知识目标和操作学习任务；如需引图或摘录须先确认版权和实验室许可。

## 官方公开资料（可直接访问）

- [Oxford Instruments / WITec Academy](https://raman.oxinst.com/library/academy) — 厂家分设仪器基础、进阶操作与 Project 数据/图像处理培训。
- [Oxford Instruments WITec Suite FIVE 软件介绍（历史官方 PDF）](https://raman.oxinst.com/assets/uploads/raman/materials/WITec-Suite-FIVE-Software.pdf) — Project FIVE、RamanTV、Filter、TrueComponent 等功能背景；实际许可需核对。
- [Oxford Instruments 软件产品页面](https://raman.oxinst.com/products/software/) — 新版本参考，不替代 Control FIVE 按钮。
- [Oxford Instruments 中文 Raman Academy](https://raman.oxinst.cn/academy) — 官方教学体系参考。

## 证据等级

- **实机已确认**：用户提供的照片/软件截图和当次设置。
- **操作 SOP 记录**：SOP 对特定设备版本的描述；只有确认实机一致后才直接执行。
- **官方公开描述**：术语和原理背景；软件版本不同可能不一致。
- **课堂解释/推导**：补充物理与数学原理，需可复算及接受质疑。
