## 授课流程

每一课固定六环：①知识框架 → ②关键物理/数学原理（所有变量讲清） → ③界面截图逐项讲解 → ④可复现操作/数据处理 → ⑤结果辨析、错误情形 → ⑥小考与保存证据。**不以只看完讲解作为通过。**

建议每周 4 节、每节 45–60 分钟，外加 1–2 次上机或离线数据练习；节奏可按实际理解调整，不因日历到期强制完成。对照实机截图持续补齐软件菜单矩阵，不对未知按钮猜测具体功能。完整课程不等于所有高级附件的操作资格，特殊模式须完成授权培训。

## 学习协作与完成标记

1. 开课：指定课号，比如“开始 W08-L02”，先从 [PROGRESS.md](PROGRESS.md) 核对状态。
2. 教学：按对应周文档逐一完成；演示始终和实际 Control FIVE / Project FIVE 版本一致。
3. 验收：回答关键问题、执行安全操作或完成离线分析，并提交截图/数据/结果解释。
4. 完成：仅在通过后提交 GitHub 更新，将 `PROGRESS.md` 对应 `- [ ]` 改成 `- [x]`，填写日期、证据和待解决问题。
5. 周结：四节通过且有一份合格周任务后勾选该周验收；必要时追加课程笔记（以课程编号命名）。

> **注意：** 不能在聊天外自动知道你是否完成学习；每次完成后在对话中进行验收并更新仓库。GitHub 是唯一持久化的课程进度记录。
